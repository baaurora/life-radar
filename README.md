# Life Radar

A tiny radar chart for quarterly Wheel of Life check-ins.

Scores live in the URL fragment, so they never reach a server:

`https://baaurora.github.io/life-radar/#s=6,8,7,5,7,6&t=Q4%202026`

Order: Finances, Relationships, Personal goals, Business, Health, Spirituality. Add `&p=...` to overlay last quarter.

Chart.js 4.4.1 is vendored (MIT).
